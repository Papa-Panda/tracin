1核心命题 Core Proposition

One-sentence proposition

不用 Hessian，把训练过程中每个 checkpoint 上的梯度点积加起来估计训练样本的影响 —— TracIn 是工程上把 Influence Functions 做到大模型可用的版本，也是当前 LLM 数据清洗最实用的基线。

直觉：既然模型是 SGD 一步步"走"出来的，影响就应该是整条轨迹上"谁推了谁一把"的累积 —— 而不是在终点处用二阶近似反推。

2关键公式 Key Formulas

TracInCP estimator & self-influence · 纯文本近似，无需外部渲染

TracInCP 估计量
TracIn(z, z') = Σt ηt · ∇L(z', θt)T ∇L(z, θt)
  • z 训练样本 training example；z' 测试/目标样本 test example
  • θ_t 第 t 个 checkpoint 的模型参数
  • η_t 该 checkpoint 对应的学习率 learning rate
  • ∇L 损失对参数的梯度；点积 > 0 = helpful，< 0 = harmful
Self-influence（脏数据探测器）
TracIn(z, z) = Σt ηt · ‖∇L(z, θt)‖²
  • 令 z' = z：分数越高，模型越靠死记这条样本才能记住它
  • 把训练集按 self-influence 排序，Top 1% 拿去人工看，基本是 mislabeled / 孤岛代码 / 极长尾 API / 标签矛盾的重复数据
  • Google 用这个思路清掉 10% 数据而不掉点

工程近似 TracInCP：只用 checkpoint 快照，忽略同一 checkpoint 内不同 step 的差异，并在 batch 内近似 —— 两次 backward + 一次点积，比 Influence Functions 快 10–100x。

6Demo 结构 tracin_demo.py

80 行最小复现 · CPU 可跑 · python tracin_demo.py

造数据：200 条 20 维 toy 数据，随机翻转 10% 标签当脏数据
X = randn(200, 20); y = (X @ true_w > 0);  # 注入 20 条噪声标签
2
训练 + 存 checkpoint：线性模型，SGD(lr=0.1) 训 3 个 epoch，每 epoch 存一份参数快照
checkpoints.append({k: v.clone() for k, v in model.state_dict().items()})
3
算 self-influence：对每条样本，在每个 checkpoint 上 backward，累积 lr·‖grad‖²
score += 0.1 * sum((p.grad**2).sum() for p in params)
4
排序输出：按分数降序，Top 10 打印 → 这些 index 疑似脏数据
influences.sort(key=lambda x: x[1], reverse=True)  # 看分布尾巴是否很长
